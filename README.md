An AI-powered Python coding assistant that helps developers improve their programming skills through interactive skill assessments, code execution, error explanation, code optimization, and AI-generated theory questions. Built using Flask and Transformer-based language models, the platform provides personalized feedback, identifies strengths and weaknesses, and recommends learning resources to support continuous improvement.

Installation: (In Command Prompt)
<br>
python -m venv env
<br>
source env/bin/activate
<br>
pip install -r requirements.txt
<br>
